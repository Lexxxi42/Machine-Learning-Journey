# Курс по машинному обучению

> Полный курс по машинному обучению: от основ до продвинутых тем.  
> Каждый проект — это отдельный репозиторий с выполненными заданиями.

## Репозитории

| # | Проект | Описание | Ссылка | Стек |
|---|---------|-------------|------|------|
| 01 | **ml-module-01** | Проект посвящен основам машинного обучения и базовому анализу данных.<br>Он помогает понять, как обучать простые модели, освоить методы анализа и обработки данных, а также их визуализации.<br>В рамках проекта необходимо создать регрессионные модели для прогнозирования стоимости аренды квартиры на основе описания объявления, фотографий, количества спален и других характеристик.<br><br>В конце проводится сравнительный анализ моделей по метрикам MAE и RMSE. | [Открыть](https://github.com/Lexxxi42/ml-module-01) | Numpy, Pandas, Seaborn, Matplotlib, Sci-kit learn |
| 02 | **ml-module-02** | Проект посвящен реализации линейных моделей в машинном обучении, в частности: <ul><li>линейная регрессия (аналитический метод и с использованием стохастического градиентного спуска);</li><li>методы регуляризации (L1, L2, ElasticNet)</li></ul>Изучение проблем переобучения и недообучения моделей.<br>Сравнительный анализ построенных моделей по метрикам: MSE, MAE, MAPE, R2.<br><br>Цель проекта — получить глубокое понимание того, как работают линейные модели для решения задач регрессии, научиться реализовывать их на Python, оценивать их качество и бороться с переобучением. | [Открыть](https://github.com/Lexxxi42/ml-module-02) | Numpy, Pandas, Seaborn, Matplotlib, Sci-kit learn |
